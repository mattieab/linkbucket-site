# Naming: replacing "Link Bucket"

Research date: 2026-10-02. Checks actually performed: Google Play web search pages (fetched), Apple App Store via `site:apps.apple.com` web search, RDAP lookups for .app (Google Registry RDAP, `pubapi.registry.google`) and .com (Verisign RDAP, `rdap.verisign.com`), general web search. **Not performed:** USPTO / EUIPO / TMview / WIPO trademark searches (all are JS single-page apps that could not be queried from this environment) — trademark status of every name below is UNVERIFIED and must be checked by hand before committing.

RDAP convention used below: `404` = no registration record (very likely unregistered/available), `200` = registered. A 404 is not a guarantee (premium/reserved names can still be unbuyable); confirm at a registrar.

## What does "Link Bucket" / "LinkBucket" collide with?

### Takeaway
"Linkbucket" is an active bookmark/link-saving product with its own .app domain, browser extensions and a mobile app, plus an Android app called "LinkBucket - Bookmark Manager" and several Chrome extensions; the "bucket" + "later" naming space for link savers is crowded on both stores.

### Cited Findings
- linkbucket.app is a live bookmark service: one-click save, full-text search, backups, browser extension for Chrome/Firefox, and a mobile version — [Linkbucket](https://linkbucket.app/); browser extensions repo — [GitHub linkbucket/browser-extensions](https://github.com/linkbucket/browser-extensions)
- An Android app "LinkBucket - Bookmark Manager" (package com.kamuk.bookmark) exists — [APKPure](https://apkpure.com/linkbucket-bookmark-manager/com.kamuk.bookmark)
- Older open-source "Linkbucket, the free and open-source alternative to Pocket" (archived 2020) and linkbucket-go — [GitHub ivan-avalos/linkbucket](https://github.com/ivan-avalos/linkbucket); [linkbucketgo.avalos.me](https://linkbucketgo.avalos.me/)
- Chrome extensions named "Link Bucket Extension" and "linkbucket" — [Chrome Web Store](https://chromewebstore.google.com/detail/link-bucket-extension/bhglploadpebgakocohocjckndpaamah); [Chrome Web Store](https://chromewebstore.google.com/detail/linkbucket/ledhgpcfganammeghejnclhionhhkpjp); a Facebook page @linkbucket — [Facebook](https://www.facebook.com/linkbucket)
- Adjacent names: "Bucket" bookmarking app on Google Play — [Google Play](https://play.google.com/store/apps/details?id=space.aevr.bucket&hl=en_US); "Later Bucket" link saver on iOS — [App Store](https://apps.apple.com/app/later-bucket/id6749404961)
- RDAP (performed): linkbucket.app = 200 (registered), linkbucket.com = 200; laterbucket.app = 200, laterbucket.com = 404.

### Inferences
- Avoid "bucket", "later", "stash" and "links"-as-head-noun constructions: each already has several direct link-saver competitors (see next sections). A name needs a distinct head word.

### Gaps
- Whether "LINKBUCKET" is a registered trademark anywhere was not checked (trademark databases not queried).

## Store collisions (Google Play, App Store) for finalists

### Takeaway
"Later…", "Stash", "Cubby", "Stow", "Tidy" and "Queue" are all busy prefixes; exact-match names Queuelet, Stowlinks, Linksill, Laterling, Tidy Queue had no exact app on Play. The single most relevant competitor discovered is "LaterBox", a local-first link inbox on iOS, which also rules out Later-prefixed names.

### Cited Findings
- Play search "queuelet": no app named Queuelet; queue-management apps (QueueBee, Queue, Queueless, QueueCut) dominate — [Google Play search](https://play.google.com/store/search?q=queuelet&c=apps)
- Play search "queue read later": "Queued: Save for Later" (Axenrai Innovations) is a read-later link saver; "Queue - Find Movies & Shows" (Watch Queue, Inc.) — [Google Play search](https://play.google.com/store/search?q=queue%20read%20later&c=apps)
- Play search "stowlinks": "No results for stowlinks" — [Google Play search](https://play.google.com/store/search?q=stowlinks&c=apps). Play search "stow": ten "Stow…" apps (STOW, Stowlog, StowQR, "Stow - Find What You Put Away", etc.), none link/bookmark savers — [Google Play search](https://play.google.com/store/search?q=stow&c=apps)
- Play search "laterlet"/"laterling": LaterLinks: Bookmark Saver, Later - Save for Later, Later (xotoxstudio), Latero, Latera, Laterly — [Google Play search](https://play.google.com/store/search?q=laterling&c=apps); [Google Play search](https://play.google.com/store/search?q=laterlet&c=apps)
- App Store: LaterLinks, LaterBox ("local-first inbox for links"), Laterfy, LinkStash, linklater, Stash - Save & Organize Links, "links for later", Link Dock exist — [LaterLinks](https://apps.apple.com/us/app/laterlinks-ready-when-you-are/id6756243221); [LaterBox](https://apps.apple.com/mx/app/laterbox/id6756787808); [LinkStash](https://apps.apple.com/py/app/linkstash/id6746194438); [linklater](https://apps.apple.com/ca/app/linklater/id1584796899); [Stash](https://apps.apple.com/hn/app/stash-save-organize-links/id6541751295); [Link Dock](https://apps.apple.com/ar/app/link-dock/id6776985727?l=en-GB); also "Later: Save links, read later" — [App Store](https://apps.apple.com/us/app/later-save-links-read-later/id1507396839)
- `site:apps.apple.com` search returned nothing named Queuelet, Stowlinks or Laterling — [web search, 2026-10-02; results listed above]
- Play search "cubby links": all ten results are "Cubby …" apps (Cubby: Find Where Things Are, Cubby - for your collectibles, Cubby: File Manager, Cubby — Kids Launcher, Cubby: Tool Tracker…) — [Google Play search](https://play.google.com/store/search?q=cubby%20links&c=apps)
- Play search "sill links": "Sillside: Friends Photo Widget" and "Sill Home"; no link savers — [Google Play search](https://play.google.com/store/search?q=sill%20links&c=apps)
- Play search "tidy queue": many "Tidy …" cleaning/puzzle apps, none named Tidy Queue — [Google Play search](https://play.google.com/store/search?q=tidy%20queue&c=apps); web: "TidyQueue" is a small add-on for the game Return of Reckoning — [GitLab](https://gitlab.com/ror-addons/tidyqueue)
- Play search "docket links": a "Docket" app (SWS APP Developer) — [Google Play search](https://play.google.com/store/search?q=docket%20links&c=apps)
- Play search "link tote": no "tote" apps; LaterLinks, Linkzary, LinkIt, Link Organizer, Linkora appear — [Google Play search](https://play.google.com/store/search?q=link%20tote&c=apps)

### Inferences
- Laterling / Laterlet / Laterbasket: drop — too close to LaterLinks, Later, Laterly and especially LaterBox (same local-first positioning).
- Link Docket: drop — too close to "Link Dock" on iOS.
- Cubby Links: weak — "Cubby" is saturated on Play; store search for "cubby" will never surface it.
- Queuelet: closest neighbour is "Queued: Save for Later"; distinct enough in spelling, but worth noting.

### Gaps
- Upnext Links, Queue Shelf, Stowtray were not store-searched (tool budget). App Store checks rely on web search indexing, not on-device App Store search, so recent or unindexed iOS apps could be missed.

## Web/SEO collisions and language checks

### Takeaway
"Link Tote" / "Totelinks" / "Latertote" must be rejected: in German "tote Links" means "dead links". Queuelet is SEO-clean (web search returns no product of that name) but has the weakest spelling-from-hearing.

### Cited Findings
- "Tote Links" = dead links in German ("Toter Link"; a Chrome extension "Tote Links finden" = "find dead links") — [Wikipedia DE: Toter Link](https://de.wikipedia.org/wiki/Toter_Link); [Chrome Web Store](https://chromewebstore.google.com/detail/tote-links-finden/eiapdnamnopdeokkmmkdbikhlncgdeno?hl=de)
- Web search for "Queuelet" returned no product with that name, only generic queue pages — [web search results incl. Queue-it](https://en.wikipedia.org/wiki/Queue-it)
- "Linktote/Link Tote" web results are dominated by fashion "Links Tote" handbags — [letsbagitonline](https://letsbagitonline.com/products/links-tote)

### Inferences (own language judgement, not sourced)
- Queuelet: English "KYOO-let". Non-native speakers (DE/FI/ES) often cannot spell "queue" from hearing ("kjulet", "qulet") — a real word-of-mouth cost; but ranks easily since it's unique. No bad meanings found in EN/DE/FI/ES.
- Linksill ("Sill" brand): easy to say/spell in all four languages. Swedish/Finland-Swedish "sill" = herring (harmless, mildly funny); Spanish "silla" = chair. Metaphor (windowsill: where you set things you'll grab on the way out; small, fixed space on the home screen) fits "small queue + widget". Risk: "link sill" may be read as "links ill" in lowercase — use camel case LinkSill.
- Stowlinks: easy in all languages; German "Stau" (traffic jam) only by sound. But "stow" connotes putting away long-term, which contradicts "a queue, not a graveyard".
- Tidy Queue: two plain words, easy, carries the "queue" keyword and the "get through it" promise; "Tidy" is very generic on Play so brand distinctiveness is low.
- Queue Shelf / Stowtray / Upnext Links: pronounceable, no bad meanings; Upnext is generic ("Up Next" is common media phrasing), so low brand ranking.

### Gaps
- No search-volume data for "read later" / "watch later" / "link queue" keywords; keyword value is judged qualitatively.

### Takeaway
